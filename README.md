# ကျော်ကြီးနဲ့ ကျန်ကြီး  
## မပြောင်းလဲနိုင်သော်လည်း မပြီးဆုံးနိုင်တဲ့အချစ်

ဒီဇာတ်လမ်းက လူ့အသိုင်းအဝိုင်းရဲ့ မလက်ခံနိုင်မှု၊ ကိုယ့်ကိုယ်ကိုယ် ရှာဖွေမှု၊  
နာကျင်မှုတွေကြားက မပြောင်းလဲတဲ့ အချစ်အကြောင်းကို ဖော်ပြထားတဲ့ ဖန်တီးမှုဝတ္ထုတိုတစ်ပုဒ် ဖြစ်ပါတယ်။

---

## အကျဉ်းချုပ်

ကျော်ကြီးနဲ့ ကျန်ကြီးက လူငယ်ဘဝကတည်းက အမြဲအတူရှိခဲ့တဲ့ သူငယ်ချင်းတွေပါ။  
ကျော်ကြီးက ကိုယ့်ကိုယ်ကိုယ် ယောကျာ်းမဟုတ်ဘူးလို့ ခံစားနေရပြီး  
ထိုင်းကိုသွားကာ ကိုယ့်ဘဝကို ပြောင်းလဲဖို့ ဆုံးဖြတ်ခဲ့ပါတယ်။

လူ့အသိုင်းအဝိုင်းရဲ့ ဖိအားတွေ၊ မိသားစုရဲ့ မလက်ခံနိုင်မှုတွေကြားမှာပဲ  
သူတို့ရဲ့ အချစ်က ပိုပြီး နက်ရှိုင်းလာခဲ့ပါတယ်။

ဒါပေမယ့် ကံကြမ္မာရဲ့ စမ်းသပ်မှုအနေနဲ့  
ကျော်ကြီးက AIDS ရောဂါနဲ့ ကြုံတွေ့ရပြီး  
အချစ်ဆိုတာ မပြောင်းလဲနိုင်ပေမယ့်  
ဘယ်တော့မှ မပြီးဆုံးနိုင်ဘူးဆိုတာကို  
နာကျင်စရာအဆုံးသတ်နဲ့ ပြသသွားပါတယ်။
